# Pass Validation Rules — Safed Sheri

## 1. Complete Rule Checklist

Entry validation requires all 9 server-enforced conditions to pass:

1. **Pass Record Exists:** Verified in server database.
2. **Authorized Source:** Pass generated by verified web app / WhatsApp flow.
3. **Pass Activated:** `pass_status == PASS_ACTIVATED` or `READY_FOR_ENTRY`.
4. **Payment Verified:** `payment_status == PAYMENT_VERIFIED`.
5. **Cryptographic QR Authentic:** Signature match validated by server.
6. **Pass Unused:** `is_used == false`.
7. **Identity Verification:** Attendee name / phone matches booking record.
8. **Face Authentication:** Live photo / biometric match against reference.
9. **White Dress Code Compliance:** Verified physically by Entry Verification Officer.
