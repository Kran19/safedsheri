# QR Code System Architecture — Safed Sheri

## 1. Backend-Authenticated QR Model

QR codes generated by the Safed Sheri platform are cryptographically authenticated tokens, rather than plain text JSON payloads.

```text
[ Digital Pass Card ] ──► Displays Cryptographic QR Payload (e.g. ss_pass_v1_9f8b7a6c...)
                                   │
                                   ▼ (Scanned at Gate)
                           [ Gate Scanner App ]
                                   │
                                   ▼ (HTTPS / Signed API)
                        [ Safed Sheri Backend ]
                                   │
                           (Validates Token, Payment, Face Auth, Usage State)
```

## 2. Security Against Fraud & Screenshots

1. **No Static Data in Payload:** The QR contains a secure token key (e.g. UUIDv4 or HMAC-SHA256 signature). Scanning the code without hitting the server reveals no personal data.
2. **One-Time Usage Lock:** Scanning a QR marks `is_used = true` in an atomic transaction (`SELECT FOR UPDATE`). Duplicate scans trigger an instant `ALREADY USED` alert.
3. **Anti-Screenshot Mitigations:** Dynamic QR refreshes or mandatory live face authentication at the gate ensure forwarded images cannot grant entry.
