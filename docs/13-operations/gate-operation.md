# Gate Operational Protocol — Safed Sheri

## 1. On-Site Gate Security Operations

Entry Verification Officers operate mobile handheld scanner devices positioned at event access lanes.

## 2. Standard Operating Procedure (SOP)

1. **Scan:** Officer aligns device camera with attendee's digital pass QR code.
2. **System Check:** Device displays instant validation result (`APPROVED` / `DENIED`).
3. **Identity & Face Auth:** Officer checks stored reference image / automated face verification match score.
4. **Dress Code Inspection:** Officer verifies that attendee is wearing mandatory white attire.
5. **Clear Entry:** Officer taps "Approve Entry" button, marking pass `USED` and admitting attendee into venue.
