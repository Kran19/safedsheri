# Cash Counter Operational Protocol — Safed Sheri

## 1. On-Site Counter Operations

Physical cash counters operate using tablet or desktop devices connected to high-priority local Wi-Fi / cellular backhauls.

## 2. Standard Operating Procedure (SOP)

1. **Search:** Executive asks for attendee Booking Ref or Phone Number.
2. **Verify Amount:** Interface displays exact cash amount required. No manual amount entry allowed without override.
3. **Collect & Count Cash:** Executive counts cash physically.
4. **Confirm System Activation:** Executive clicks "Confirm Cash Received". System marks payment `VERIFIED` and pass `ACTIVATED`.
5. **Receipt Dispatch:** System dispatches instant WhatsApp receipt and active digital pass link.
