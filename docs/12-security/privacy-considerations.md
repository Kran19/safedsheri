# Privacy & Data Protection Considerations — Safed Sheri

## 1. Minimal Data Collection Policy

Safed Sheri collects only essential operational data:
* Full Name
* WhatsApp-verified Phone Number
* Booking Reference & Payment Records
* Reference Image / Biometric Embedding for Event Entry

Unnecessary personal data (such as home addresses, government ID numbers, or financial account details) is explicitly excluded from collection.

## 2. Data Storage & Retention Protocols

* All sensitive communications use TLS 1.3 encryption in transit.
* Personal identifiable information (PII) is encrypted at rest using AES-256.
* Attendance and pass records are archived after event completion in accordance with local regulations.
