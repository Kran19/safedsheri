# Super Admin Modules — Safed Sheri

## 1. Module Overview

The Super Administrator Portal is organized into 11 distinct management modules.

```text
+-------------------------------------------------------------------------+
|                      SUPER ADMIN DASHBOARD MODULES                      |
+--------------------+--------------------+-------------------------------+
| 1. Event Admin     | 5. Finance Engine  | 9. Stall Application Engine   |
| 2. Pricing Phases  | 6. Attendees       | 10. Staff Account Management  |
| 3. Gazebo Grid     | 7. Gate Monitor    | 11. System Audit Logs         |
| 4. Bookings Master | 8. Sponsor Pipeline|                               |
+--------------------+--------------------+-------------------------------+
```

## 2. Module Descriptions

1. **Event Admin:** Configure multi-year event editions, venues, dates, and active event toggles.
2. **Pricing Phases:** Dynamic setup for Early Bird, Phase 1, Phase 2 dates and prices.
3. **Gazebo Grid:** Real-time inventory status for Level 1, 2, and 3 gazebos (12 total).
4. **Bookings Master:** Searchable master table of all reservations, payment states, and pass statuses.
5. **Finance Engine:** Track cash counter activities, shift balances, and verify cash collection.
6. **Attendees Directory:** User profile management, linked WhatsApp numbers, and pass records.
7. **Gate Entry Monitor:** Live event-night gate metrics (Scan rate, Approval %, Rejections, Gate throughput).
8. **Sponsor Pipeline:** Review and manage commercial sponsor leads.
9. **Stall Pipeline:** Review and assign vendor stall applications.
10. **Staff Account Management:** Provision credentials for Finance Executives and Entry Officers.
11. **System Audit Logs:** Searchable immutable audit logs for all security and financial actions.
