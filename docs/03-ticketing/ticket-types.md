# Ticket Types — Safed Sheri

## 1. Ticket Hierarchy

Safed Sheri offers two main tiers of passes: **Standard Passes** (Single / Couple) and **Gazebo Passes** (Level 1 / 2 / 3).

```text
                           ┌───────────────────────────┐
                           │      PASS HIERARCHY       │
                           └─────────────┬─────────────┘
                                         │
                 ┌───────────────────────┴───────────────────────┐
                 ▼                                               ▼
      ┌────────────────────┐                          ┌────────────────────┐
      │   STANDARD PASS    │                          │    GAZEBO PASS     │
      ├────────────────────┤                          ├────────────────────┤
      │ * Single Pass      │                          │ * Level 1 Gazebo   │
      │ * Couple Pass      │                          │ * Level 2 Gazebo   │
      │                    │                          │ * Level 3 Gazebo   │
      └────────────────────┘                          └────────────────────┘
```

## 2. Standard Pass Definitions

1. **Single Pass:**
   * Entitles 1 individual attendee to venue entry.
   * Subject to compulsory white dress code and face authentication.
   * Strictly non-transferable.
2. **Couple Pass:**
   * Entitles 1 couple (2 individuals) to venue entry.
   * Requires attendee details for both individuals.
   * Both individuals must comply with white dress code and pass face verification.
